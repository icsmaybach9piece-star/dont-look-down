# Don't Look Down

A cosmic-horror Metroidvania for the Game Boy Advance.

Iggy Pop versus the god-like entities that lurk in the Good Night.

- Target: GBA (240x160, ARM7TDMI)
- Built automatically via GitHub Actions (devkitARM)
- ROM output: `DLD.gba`

## Status

Part 0 — pipeline proof. A movable placeholder sprite on a colored screen.
